📖 API 接口文档
GET /api
参数名类型必填默认值说明
server string 否 netease 音乐平台：netease 网易云、tencent QQ音乐、kugou 酷狗、baidu 百度、kuwo 酷我、xiami 虾米
type string 是 — 请求类型，见下方支持矩阵
id string 是 — 资源 ID：歌单 ID、歌曲 ID 等
🔢 类型支持矩阵
type 值说明neteasetencentkugoubaidukuwo
song单曲信息✓✓✓✓✓
playlist歌单✓✓✓✓✓
url播放链接✓✓✓✓✓
lrc歌词✓✓✓✓✓
pic封面图片✓✓✓✓✓
name歌曲名✓✓✓✓✓
artist歌手✓✓✓✓✓
🔍 请求示例
cURL
curl "https://你的域名/api?server=netease&type=playlist&id=2619366284"
